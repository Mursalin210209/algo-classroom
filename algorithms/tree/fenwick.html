Fenwick Tree
aka Binary Indexed Tree (BIT)

A compact array where each index i stores the sum of lowbit(i) elements — the count given by its lowest set bit. Prefix queries and point updates both run in O(log N) using only the operation i ± (i & -i).

Intermediate
Build: O(N log N)
Prefix Query: O(log N)
Point Update: O(log N)
Space: O(N)
Key op: i & (-i)
🔋
lowbit(i)
i & (-i) isolates the lowest set bit. BIT[i] stores the sum of the last lowbit(i) elements.
⬆️
Update
Add delta to index i, then jump to i + lowbit(i). Each update touches O(log N) nodes.
⬇️
Prefix Query
Sum [1..i]: accumulate BIT[i], then jump to i - lowbit(i). Peel off bits until i = 0.
📐
Range Query
Sum [l..r] = query(r) - query(l-1). Two prefix sums give any range.
💡
Why It Works
Every prefix [1..i] decomposes into O(log N) non-overlapping power-of-2 ranges — one per set bit in i.

💻 Pseudocode
function query(i): # prefix sum [1..i] s = 0 while i > 0: s += BIT[i] # accumulate i -= i & (-i) # strip lowbit return s
function update(i, delta): # add delta while i <= n: BIT[i] += delta # update i += i & (-i) # add lowbit # O(log N) nodes touched
function range(l, r): return query(r) - query(l - 1) # = sum[1..r] - sum[1..l-1] # = sum[l..r]
