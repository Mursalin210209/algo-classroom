Preorder Traversal

Beginner

Visit every node in Root → Left → Right order. Preorder is a depth-first traversal that processes each node before its children — essential for copying trees, generating prefix expressions, and serialization.

Time: O(N)
Space: O(H)
Structure: Call Stack
Order: Root → L → R
Strategy: DFS
📋
Root First
Visit (record) the current node before recursing into its left or right subtrees. Hence "pre" — before children.
↙️
Go Left Deep
After visiting the root, recurse fully into the left subtree, exploring every left branch to completion.
↘️
Then Right
Once the entire left subtree is exhausted, recurse into the right subtree with the same Root→L→R rule.
📦
Call Stack
Each recursive call is pushed onto the call stack. The stack unwinds as we backtrack, driving the left-then-right order.
