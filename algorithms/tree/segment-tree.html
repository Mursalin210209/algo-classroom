Segment Tree

Intermediate

A binary tree built over an array where each node stores an aggregate (sum, min, max) of a subarray range. Supports both range queries and point updates in O(log N) — far faster than brute-force O(N) per query.

Build: O(N)
Query: O(log N)
Update: O(log N)
Space: O(4N)
Array size: 2·2^⌈log N⌉
🏗️
Build O(N)
Recursively split the array in half. Each leaf holds one value; each internal node holds the aggregate of its two children.
🔍
Range Query O(log N)
Traverse the tree, collecting nodes whose ranges are fully inside the query range and skipping those fully outside.
✏️
Point Update O(log N)
Update a leaf, then propagate the change upward — recomputing each ancestor's aggregate on the way back to the root.
✂️
Three Cases
During a query each node is either: fully inside (use it), fully outside (skip), or partially overlapping (recurse into children).
📦
Array-Backed
Stored in a flat array: node 1 is root, left child of node i is 2i, right child is 2i+1. No pointers needed.

💻 Pseudocode
function build(node, start, end): if start == end: # leaf tree[node] = arr[start] else: mid = (start + end) / 2 build(2*node, start, mid) build(2*node+1, mid+1, end) tree[node] = tree[2*node] + tree[2*node+1]
function query(node, start, end, l, r): if r < start or end < l: # no overlap return 0 if l <= start and end <= r: # full overlap return tree[node] mid = (start + end) / 2 # partial left = query(2*node, start, mid, l, r) right = query(2*node+1, mid+1, end, l, r) return left + right
function update(node, start, end, idx, val): if start == end: # found leaf arr[idx] = val tree[node] = val else: mid = (start + end) / 2 if idx <= mid: update(2*node, start, mid, idx, val) else: update(2*node+1, mid+1, end, idx, val) tree[node] = tree[2*node] + tree[2*node+1]
