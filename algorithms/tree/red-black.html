Red-Black Tree

Advanced

A self-balancing BST where every node is colored Red or Black. Five invariants guarantee O(log N) height — maintained after every insertion via recoloring and rotations.

Search: O(log N)
Insert: O(log N)
Delete: O(log N)
Height: ≤ 2·log₂(N+1)
Space: O(N)
🔴⚫
Two Colors
Every node is Red or Black. The root and all null leaves (NIL sentinels) are always Black.
🚫🔴
No Red-Red
A Red node's parent must be Black. Two consecutive Red nodes violate the invariant and trigger a fix-up.
⚫=⚫
Black Height
Every path from any node to a descendant NIL leaf contains the same number of Black nodes (black-height).
🔄
Rotations
Left and Right rotations restructure the tree locally in O(1) to restore balance without violating BST order.
🎨
Recoloring
When a Red uncle exists, flip parent/uncle to Black and grandparent to Red, then propagate the fix upward.
