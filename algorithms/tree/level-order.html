Level Order Traversal

Beginner

Visit every node level by level, left to right, starting from the root. Unlike DFS traversals, level order uses a queue (BFS) — making it ideal for finding shortest paths, printing trees by depth, and serialization.

Time: O(N)
Space: O(W)
Structure: Queue (BFS)
Order: Level by Level
Strategy: BFS
📬
Queue — Not Stack
Level order uses a FIFO queue, not recursion. Enqueue the root, then repeatedly dequeue and enqueue children.
🏗️
Level by Level
All nodes at depth 0 are visited before depth 1, depth 1 before depth 2 — a "breadth-first" sweep of the tree.
↔️
Left Before Right
Within each level, nodes are visited left to right because left children are enqueued before right children.
📏
Shortest Path
BFS guarantees the first time a node is reached is via the fewest edges — key for shortest-path problems on trees and graphs.
