Lowest Common Ancestor

Intermediate

Given two nodes P and Q in a tree, find their Lowest Common Ancestor — the deepest node that is an ancestor of both. Three classic algorithms: Naive path climbing, Euler Tour + RMQ, and Binary Lifting.

Naive: O(H)
Binary Lifting: O(log N)
Euler Tour+RMQ: O(1) query
Preprocess: O(N log N)
Space: O(N log N)
🧬
Ancestor
Node A is an ancestor of B if A lies on the path from the root to B. Every node is its own ancestor.
⛰️
Naive Climbing
Bring the deeper node up to the same depth, then climb both pointers simultaneously until they meet.
🚀
Binary Lifting
Precompute 2^k-th ancestors for each node. Jump in powers of two to find LCA in O(log N) per query.
🌀
Euler Tour + RMQ
Flatten the tree into an Euler tour array, then LCA(u,v) = minimum-depth node between first occurrences of u and v.
🏔️
LCA = Meeting Point
The LCA is where the root-to-P and root-to-Q paths diverge. It's the deepest node shared by both paths.

💻 Algorithm (pseudocode)
function LCA_naive(p, q): dp = depth(p); dq = depth(q) while dp > dq: # equalize depth p = p.parent; dp-- while dq > dp: q = q.parent; dq-- while p != q: # climb together p = p.parent q = q.parent return p # LCA found!
# Precompute: up[v][k] = 2^k-th ancestor function LCA_lift(p, q): if depth[p] < depth[q]: swap(p,q) diff = depth[p] - depth[q] for k in range(LOG): # lift p up if (diff >> k) & 1: p = up[p][k] if p == q: return p for k in range(LOG-1,-1,-1): if up[p][k] != up[q][k]: p = up[p][k]; q = up[q][k] return p.parent # LCA!
# Euler tour: visit node each time # euler[], first[v] = first occurrence function buildEuler(node, depth): euler.append(node) first[node] = euler.length - 1 for child in node.children: buildEuler(child, depth+1) euler.append(node) # revisit function LCA_euler(p, q): lo = min(first[p], first[q]) hi = max(first[p], first[q]) return RMQ(euler, lo, hi) # min depth
